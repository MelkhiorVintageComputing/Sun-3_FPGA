# Sun 3/60 PROM Rev 1.9: run without parity hardware.
#
# The replica has no parity memory, no memory error interrupt and a memory
# error register that only stores what is written to it.  The stock PROM
# enables parity checking, tests it (self tests 0x0E and 0x0F force parity
# errors and expect the level 7 interrupt), and reads the memory error
# register from its NMI handler.  These patches take all of that out.
#
# Transcribed word for word from the verified RomPatcher set in
# Old/VintageBusFPGA_Common/RomPatcher/Sun3_60NoParity (rompatch.s there has
# the source); the words below are its output diffed against the pristine
# image.  0x0fe08000 is the monitor's virtual address for the memory error
# register (OBIO 0x80000).
#
# Line format: <address> <expected> <new>   (hex, 16-bit words, PROM at 0x0fef0000)

# fixIrq7Handler: the level 7 handler does `move.b 0x0fe08000,%d0'; make it
# `move.b #0,%d0; nop' so it never reads the memory error register.

0fef03a6 0fe0 0000
0fef03a8 8000 4e71
